解锁靠的是 DNS 方案，不是原生住宅 IP。AKDNS 已经支持 DNS over TCP，官方说明是"UDP 53 被封锁或污染时也能稳定解锁，脚本自动检测并切换 TCP"。JPHyper 这类节点则强调"内置 AKILE DNS 日本内网解锁"。
